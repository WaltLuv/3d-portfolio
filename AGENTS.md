# AGENTS.md — Walter Thornton 3D Portfolio

## Product Goal

This repository is Walter Thornton's employer-facing immersive 3D portfolio.

It must function simultaneously as:

1. a professional portfolio
2. a cinematic interactive world
3. a game-like real-estate experience
4. a product ecosystem showcase and navigation hub

## Creative North Star

The portfolio should feel like the cinematic portfolio version of the 3D PropControl Empire world.

Do not redesign it as:
- generic SaaS
- command center
- cyberpunk dashboard
- ordinary developer portfolio
- collection of glowing cards

The physical property world should be warm, architectural, tactile, and believable.
The AI layer should be holographic cyan/blue with restrained violet accents.

## Ecosystem

The core ecosystem is:
- PropControl
- VoiceOps
- VisionOps
- Workforce OS
- Baseline Studios / Arkitech

Roles:
- PropControl = operate the real-estate world
- VoiceOps = hear the world
- VisionOps = see the world
- Workforce OS = coordinate, govern, and execute AI work
- Baseline Studios / Arkitech = create new AI capabilities

At least one property event should visibly move through the full loop:

VoiceOps → PropControl → VisionOps → Repair Cost Guide → Workforce OS → Baseline Studios / Arkitech → Workforce OS → PropControl → physical world.

## Repair Cost Guide

Repair Cost Guide quote/estimate generation is a signature VisionOps moment. Do not bury it in copy.

## Walter

Walter is the recurring protagonist and guide. Do not fabricate professional claims. Do not create a low-quality fake 3D character merely to check a box.

## Professional Portfolio

Preserve verified About, professional background, experience, How I Build, capabilities, projects, resume, GitHub, contact, and other verified professional information.

The immersive world must not erase the professional information layer.

## Product Links

Use verified landing-page URLs only. Never invent URLs and never use `#` as a fake destination. Keep product destinations centralized.

## Accessibility

Critical information must remain semantic HTML. WebGL is the experiential layer, not the sole information layer. Respect reduced motion.

## Performance

Optimize 3D intelligently instead of deleting the experience.

## Blender

When useful, inspect `WaltLuv/CLI-Anything`, especially:
- `codex-skill/SKILL.md`
- `skills/cli-anything-blender/SKILL.md`

Verify Blender and the CLI are actually available before claiming use.

## Visual Verification

Where browser/preview tools are available: run → view → critique → fix → repeat.
Do not claim visual verification when graphical inspection was unavailable.

## Git

Protect `main`. Use feature branches. No force pushes. Run lint/build before merge.

## Definition of Done

The project is not done simply because tests pass. It must clearly communicate one connected AI real-estate ecosystem and remain a strong professional portfolio.
