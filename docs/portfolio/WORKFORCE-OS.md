# Workforce OS — Hidden Workforce Reveal

Workforce OS is a major world reveal, not another product card.

## Narrative

After VoiceOps, PropControl, VisionOps, and Repair Cost Guide have created work and artifacts, the visitor should ask:

What is coordinating all of this?

Follow the work beneath / behind the physical property world.

Reveal:

WORKFORCE OS
AI WORKFORCE GOVERNANCE & EXECUTION

## Core message

THE PROPERTY IS WHAT YOU SEE.
THE WORKFORCE IS WHAT MAKES IT MOVE.

- agents

## Example workflow

VoiceOps Intake
→ Maintenance Task
→ Property Context
→ Inspection Request
→ VisionOps Evidence
→ Repair Cost Artifact
→ Owner Approval
→ Vendor / Project Action
→ PropControl Update
→ Resident Follow-Up
→ Completion
→ Audit Evidence

Clearly distinguish automated execution from human approval gates.

## Visual metaphor

Avoid a generic neural network or dashboard.

Prefer something architectural:
- underground infrastructure
- transit/workflow network
- operations nervous system
- dimensional task-routing system
- platforms, routes, gates, artifacts, and controlled workstreams

After showing one workflow, pull back and reveal controlled workstreams across the wider property world.

Then transition into Baseline Studios / Arkitech by following one capability backward to its origin.
