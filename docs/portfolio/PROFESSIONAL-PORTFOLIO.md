## Product landing pages

Every product needs a clear path to its verified landing page:
- PropControl
- VoiceOps
- VisionOps
- Workforce OS
- Baseline Studios / Arkitech

Use real URLs only.
Never invent domains or deployment URLs.
Never use `#` as a fake destination.

If a URL is not verified:
- leave it unset
- hide the external CTA gracefully
- report the missing destination

Centralize product URLs in one source of truth rather than scattering them across components.

## Product chapter behavior

Experience Product
= stay in the portfolio/game journey

Explore Product ↗
= open actual product landing page

Details
= optionally reveal deeper portfolio/project information

External links may open in a new tab where appropriate, using safe link attributes.

## Resume

Keep an obvious Resume entry point reachable from primary navigation.
If the actual resume asset is absent, report it instead of fabricating a file path.

## DOM accessibility

Critical links and professional content must remain semantic HTML, not WebGL-only.
