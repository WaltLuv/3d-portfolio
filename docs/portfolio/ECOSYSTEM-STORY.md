# Ecosystem Story

The portfolio is not primarily a PropControl site.

PropControl Empire provides the physical 3D world. Walter's complete ecosystem operates inside it.

Core ecosystem:
- PropControl
- VoiceOps
- VisionOps
- Workforce OS
- Baseline Studios / Arkitech

Roles:
- PropControl = operate
- VoiceOps = hear
- VisionOps = see
- Workforce OS = coordinate / govern / execute
- Baseline Studios / Arkitech = create new AI capabilities

## Signature operational mission

Use at least one clear real-estate event that travels through the entire ecosystem.

Suggested example:
Unit 204 reports an active water leak.

Flow:

VoiceOps
→ hears and understands the request

PropControl
→ creates and manages the operational event

VisionOps
→ inspects the physical condition

Repair Cost Guide
→ turns findings into repair-cost intelligence and a quote/estimate

Workforce OS
→ coordinates agents, tasks, workflows, approvals, memory, tools, artifacts, audit, and governance

Baseline Studios / Arkitech
→ reveals how new capabilities / agents are designed and deployed

Workforce OS
→ receives deployed capability

PropControl
→ receives operational result

Physical property world
→ visibly changes as work is completed

The game itself must explain the ecosystem.

## Closed-loop message

The system:
- perceives
- understands
- coordinates
- acts
- records
- can be extended

If the visitor remembers only PropControl, the ecosystem story failed.
If the visitor sees five disconnected apps, it failed.
If the visitor understands one connected AI real-estate ecosystem, it succeeded.
