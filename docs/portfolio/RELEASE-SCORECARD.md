Score each category from 1–10.

- Immediate Wow Factor — 8%
- PropControl Empire World — 7%

- World Building — 7%

## Acceptance levels

95–100: Exceptional / portfolio centerpiece

90–94: Excellent / launch-ready

85–89: Strong but needs one more targeted visual pass

80–84: Good site, below creative target

70–79: Competent but insufficiently immersive

60–69: 6/10 territory

Below 60: Wrong execution

## Mandatory minimums

The project cannot be called finished if any are below 8/10:
- Immediate Wow Factor
- Overall Ecosystem Story
- World Building
- Movement / Flow
- VoiceOps
- VisionOps
- Repair Cost Guide
- Workforce OS
- Baseline Studios / Arkitech
- Professional Portfolio Quality

## Automatic ecosystem failure

Fail if:
- visitor only remembers PropControl
- VoiceOps is just a waveform decoration
- VisionOps does not clearly demonstrate Repair Cost
- Workforce OS is another dashboard
- Baseline Studios / Arkitech feels disconnected
- Walter's professional information gets lost
- actual product pages are difficult to reach

## Engineering release gate

Before owner review:
- run the repository's install command if needed
- run lint
- run production build
- inspect runtime console where possible
- verify missing assets/404s
- verify chapter states and scrolling
- verify mobile/reduced motion
- verify product URLs
- verify resume link
- verify contact
- verify accessibility
- audit major asset sizes and 3D performance risks

## Git / owner review

Do not merge automatically.

Push the feature branch, provide preview/comparison/report, and wait for owner review.
